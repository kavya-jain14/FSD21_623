# Assignments

1. `01-Promises-Async-Await` demonstrates resolution, rejection, chaining, async/await and error handling.
2. `02-Product-API` contains an Express CRUD API with 100 initial products.
3. `03-Portfolio-Express` contains a responsive HTML portfolio served through Express.
4. `04-React-Express` contains a React frontend connected to an Express API.
5. [05-Campus-Help-Desk](05-Campus-Help-Desk) contains a campus problem form, persistent complaint storage, ticket search/filtering and status tracking.
6. [06-Notes-App](06-Notes-App) contains persistent student text notes with search, subject filters, editing, deletion, pinning and text downloads.

`Extra-Bouncing-Ball` preserves the controllable HTML, CSS and JavaScript animation.
