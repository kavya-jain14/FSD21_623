# Class Tasks

Run Node.js examples from the repository root:

```bash
node ClassTasks/01-JavaScript-Basics/arguments.js
node ClassTasks/02-Callbacks/callback.js
node ClassTasks/03-Asynchronous-JavaScript/promise.js
node ClassTasks/03-Asynchronous-JavaScript/async-await.js
node ClassTasks/05-File-System-Module/callback-crud.js
node ClassTasks/05-File-System-Module/promise-crud.js
node ClassTasks/06-Event-Module/node-emitter.js
node ClassTasks/06-Event-Module/button-events.js
node ClassTasks/07-HTTP-Module/server.js
```

Serve `04-Fetch-API` and `06-Event-Module/browser-events` through a local static server before opening them in a browser.
